# BrewixGames downloads

Download the latest BrewixGames for Mac from [Releases](../../releases/latest): get **BrewixGames.dmg**.

1. Open the .dmg and drag **BrewixGames** into **Applications**.
2. Open it. The first time, macOS says it can't check the developer. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to BrewixGames. You only do this once.
3. In BrewixGames, go to **Settings**: click **Install Claude Code** (if shown), then **Sign In to Claude**.

Updates: **Settings → Check for Updates → Update and Restart**.

This repo holds only the finished app. The code is private.
