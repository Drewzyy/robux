BrewixGames for Windows 10 and 11

1. Double-click INSTALL_WINDOWS.bat. It downloads the newest BrewixGames,
   installs it for your user (no admin needed), and offers to install
   Claude Code and, optionally, Ollama for free local models.
2. Double-click RUN_WINDOWS.bat any time to open BrewixGames.
3. Double-click UPDATE_WINDOWS.bat to get the newest version. Your games,
   runs, and settings are kept. The vault is backed up before it refreshes.

BrewixGames never asks for your Roblox password, cookies, or API keys, and
never publishes a game without your approval.
