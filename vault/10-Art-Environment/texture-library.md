# Texture library

Powered by Poly Haven (polyhaven.com). All Poly Haven textures are CC0: free for any use, no credit needed in your game.

## Do this
- First try Roblox's built-in materials (free, fast, look good on phones): Plastic, SmoothPlastic, Neon, Wood, WoodPlanks, Marble, Basalt, Slate, CrackedLava, Concrete, Limestone, Granite, Pavement, Brick, Pebble, Cobblestone, Rock, Sandstone, CorrodedMetal, DiamondPlate, Foil, Metal, Grass, LeafyGrass, Sand, Fabric, Snow, Mud, Ground, Asphalt, Salt, Ice, Glacier, Glass, ForceField, Cardboard, Carpet, CeramicTiles, ClayRoofTiles, RoofShingles, Leather, Plaster, Rubber. Change their colour with the part's Color.
- For a custom look on many parts, make a MaterialVariant in MaterialService from a texture below (ColorMap, NormalMap, RoughnessMap, MetalnessMap), then pick it on parts like a built-in material.
- For one special mesh, use SurfaceAppearance on the MeshPart with the same maps. See [[10-Art-Environment/realism-when-needed]].
- Andrew uploads the image files to Roblox (Creator Hub or Asset Manager); agents name the files and where they go.
- 1K maps are enough for most surfaces on phones; reuse one texture with different tints instead of many textures.
