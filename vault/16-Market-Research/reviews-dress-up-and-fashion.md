# Reviews: dress-up and fashion games
What players say makes them stay and what makes them quit in this niche, written as rules for building. Evidence is thin and mostly secondary, so treat rankings as hypotheses to test with our own data.

## Do this
- Make every core item free; sell only extras like VIP bundles.
- Time creation rounds at 3-5 minutes and show a countdown.
- Use blind or weighted voting and block repeat votes from friends to reduce bias.
- Show results with feedback so losers learn.
- Search and filter items; large item lists need categories.
- Photo or save outfit feature.

## Top 6 loved things (paraphrased review language)
1. Creativity.
2. Fun themes.
3. Friendly voting.
4. Saving outfits.
5. New items often.
6. Playing with friends.

## Top 6 hated things (paraphrased review language)
1. Paywalled best items.
2. Bias or friends voting.
3. Long lists with no search.
4. Rounds too short or long.
5. Toxic comments.
6. Lag from many accessories.

## Review-to-mechanic translation

### Build this
- Item search.
- Fair voting rules.
- Theme rotation.
- Outfit save slots.
- Accessory count cap.

### Never do this
- Never copy real fashion brand logos or items.
- Never lock winning items behind payment.
- Never show cruel rating comments to children.
- Never allow body-shaming text.

## 10-point pre-launch checklist
1. [ ] Item search.
2. [ ] Free core items.
3. [ ] Vote rules.
4. [ ] Round timers.
5. [ ] Save slots.
6. [ ] Moderation.
7. [ ] Accessory cap.
8. [ ] Theme rotation of 20.
9. [ ] Performance with 12 avatars.
10. [ ] Brand check.
