# Reviews: survival games
What players say makes them stay and what makes them quit in this niche, written as rules for building. Evidence is thin and mostly secondary, so treat rankings as hypotheses to test with our own data.

## Do this
- Make the first night survivable with a clear 3-step goal (gather, craft, shelter).
- Change the loop every 10-15 minutes: new resource, enemy or tool tier.
- Cap simulation load: despawn far entities and test on low-end phones (performance was a repeat complaint in survival summaries).
- Explain crafting in-world, not in text walls.
- Make deaths cost time, not hours of progress.
- Support friends in a squad of 2-4 with shared base.

## Top 6 loved things (paraphrased review language)
1. Building a base. Phrasing: 'my fort felt like mine.'
2. Tension of hunger, night and danger.
3. Playing co-op. Phrasing: 'we survived together.'
4. Deep crafting. Phrasing: 'always something new to make.'
5. Exploring.
6. Clear progress tiers.

## Top 6 hated things (paraphrased review language)
1. Repetitive and boring loops (How to Survive summary).
2. Bugs and persistent technical issues.
3. Performance problems (BitCraft, Craftopia summaries).
4. Cumbersome crafting or unclear instructions (Forsaken Isle, ICARUS summaries).
5. Losing everything on death.
6. Griefing by other players.

## Review-to-mechanic translation

### Build this
- Three-step first-night goal.
- Resource tiers each 10-15 minutes.
- Entity despawn radius.
- Death penalty limited to a carried portion.
- Base protection from non-team players.

### Never do this
- Never wipe the base on death.
- Never hide recipes.
- Never let grief destroy a new player's base.
- Never copy another game's creature art.

## 10-point pre-launch checklist
1. [ ] First night guided.
2. [ ] Loop changes every 15 minutes.
3. [ ] Low-end test passed.
4. [ ] Recipe UI tested.
5. [ ] Death penalty is bounded.
6. [ ] Griefing protection.
7. [ ] Co-op join test.
8. [ ] Save and rejoin test.
9. [ ] Server lag under 20 players.
10. [ ] Ending or goal for the session.
