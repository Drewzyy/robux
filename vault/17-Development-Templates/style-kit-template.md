# Style kit template

Copy this into the design doc under a `## Style kit` heading and fill every line. Each line names the vault note it follows.

## Do this
| Part | Fill in | From |
|---|---|---|
| Palette | background, surface, accent (one), text; colourblind-safe pair for anything players must tell apart | [[08-UI-UX/color-palettes]] |
| Fonts | one display font, one body font, phone sizes | [[08-UI-UX/fonts-and-text]] |
| UI motion | press, open, close, reward timings and easing; reduced-motion fallback | [[08-UI-UX/ui-animation]] |
| UI sounds | press, open, close, purchase, reward, error: one line each | [[08-UI-UX/ui-sound-pairing]], [[11-Audio/satisfying-sfx]] |
| Character motion | idle, walk, run, jump feel; attack timings if there is combat | [[09-Animation-VFX/character-movement-animations]], [[09-Animation-VFX/combat-animation]] |
| Lighting | mood preset and the values to start from | [[10-Art-Environment/lighting-presets]] |
| World motion | which cheap world animations (wind, water, day-night) | [[09-Animation-VFX/building-and-world-animation]] |
| Accessibility | text size, colourblind mode, captions, volume sliders | [[08-UI-UX/accessibility]] |
| Offers | prompt budget for this game | [[07-Monetization/offer-pressure-limits]] |
| References | which images from the game's references note shaped the look | 19-Project-Memory |
