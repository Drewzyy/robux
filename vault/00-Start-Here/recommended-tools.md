# Recommended tools (zero spend)

| Job | Tool | Cost | Notes |
|---|---|---|---|
| Code from files into Studio | Rojo | free | bundled with BrewixGames |
| Lint, format, test Luau | Selene, StyLua, Lune | free | bundled |
| Luau packages | Wally | free | only MIT/Apache/BSD-licensed packages |
| 3D models | Blender + MCP for Blender | free | Modeler agent; Poly Haven CC0 assets |
| Animation | Roblox Animation Editor, Moon Animator 2 | free | check the Creator Store listing |
| Ready-made motion | Mixamo | free (account) | test fit on Roblox rigs |
| Sound editing | Audacity | free | trim, normalise, fade |
| Sounds | ForgeGUI sheet, Roblox Creator Store free audio | free | [[11-Audio/forgegui]] |
| Images, thumbnails | Krita or GIMP | free | Splash agent makes SVG comps |
| Play-testing | Roblox Studio | free | phone and tablet emulator |
| Agents | BrewixGames with Claude, or local Ollama | your plan / free | |

## Do this
- Prefer bundled and free tools; any paid plugin needs Andrew's yes first.
- Check a plugin's reviews and creator before installing; plugins can run code in Studio.
